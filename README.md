# BR GOLF
설치 없이 index.html을 브라우저에서 여는 반응형 골프 피팅 홈페이지입니다.

브랜드 소개, 피팅 프로그램, 피팅 과정, 상담 메모 다운로드 기능이 포함되어 있습니다. 프로그램 카드 선택 시 상담 폼에 해당 프로그램이 선택됩니다. 상담 내용은 사용자의 기기에서 파일로 저장하며 서버에 전송하지 않습니다.

## 배포
이 폴더의 파일을 brgolf/golffitting 저장소 루트에 올리세요. GitHub Settings → Pages → Deploy from a branch → main → /(root)를 선택해 배포할 수 있습니다.

## 운영 전 준비
실제 매장 주소, 연락처, 운영 시간을 추가하고 예약 서비스를 연결하세요. 현재는 온라인 예약을 접수하지 않습니다. Google Fonts가 연결되지 않으면 시스템 글꼴로 표시됩니다. 골프 클럽 일러스트는 CSS로 제작했습니다.
